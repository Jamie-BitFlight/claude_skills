The purpose and explicit goals of the skill find-cause:

1. Force disambiguation of a vague investigation request into a single, confirmed, falsifiable question with explicit success criteria before any investigation begins
2. Guarantee the actual failure is reproduced firsthand (not inferred from transcripts, docs, or memory) before source code is read or theorized about
3. Classify reproduction risk (bound vs. unbound constraints) and gate autonomous execution vs. user check-ins accordingly, batching all safety questions into one interaction
4. Produce a fully-cited evidence chain (command output, file:line citations, direct observation only — never docs, training recall, absence-inference, or analogy) linking symptom to root cause via explicit DEPENDS-ON dependencies
5. Eliminate hedged/unverified causal claims by banning words like "probably"/"likely"/"I think" and requiring every unverifiable claim to be explicitly flagged with what evidence would resolve it
6. Deliver a structured, falsifiable final report (QUESTION, SUCCESS CRITERIA MET, EVIDENCE CHAIN, ROOT CAUSE, UNVERIFIED ITEMS) instead of a narrative explanation
