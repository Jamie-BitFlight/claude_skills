# Accessing Online Resources

When a verification step needs information from outside the repository, use the most authoritative source available.

## Preferred Order

1. Project-local files and code
2. Official documentation for the relevant tool or library
3. Primary source material such as the upstream repository or spec
4. Search results only as a discovery aid, not as the final authority

## Validation Rules

- Prefer sources that match the exact version or release the project uses.
- Favor direct documentation pages, upstream source, or published specs over summaries.
- Check publication or update dates when the answer may have changed recently.
- If multiple sources disagree, treat the most direct primary source as the default.

## Reporting Guidance

- Cite the specific source you used.
- Distinguish observed facts from inferences.
- Call out when the result depends on external state that may change.
