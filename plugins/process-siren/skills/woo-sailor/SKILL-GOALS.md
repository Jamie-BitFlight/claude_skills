The purpose and explicit goals of the skill woo-sailor:

1. Apply Process Siren consistently across a bounded set of process-bearing files without requiring manual invocation for each file.
2. Preserve the requested analysis, improvement, or representation semantics for every processed target while isolating unrelated failures and blockers.
3. Detect and resolve or surface process conflicts that only become visible when independently valid files are considered as one composed system.
4. Apply bulk improvements only when the composed change set preserves required cross-file contracts and can be validated coherently.
