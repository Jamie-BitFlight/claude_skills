# Root-Cause Tracing Goals

- Establish accurate, falsifiable explanations of reported failures from observable evidence,
  with firsthand reproduction where safe and available.
- Distinguish observed behavior from authoritative intent so correction decisions preserve valid
  product guarantees rather than merely satisfying an existing test.
- Keep evidence, causal dependencies, and unresolved uncertainty auditable; never present an
  incomplete investigation as a proven root cause.
- Protect affected systems and respect authorized scope throughout investigation.
