# Skill Goals

1. Define direct close validation for every claimed behavior change independently of whether new regression protection is retained.
2. Admit only maintained tests whose risk reduction justifies recurring ownership cost, preferring the highest stable contract altitude that remains discriminating.
3. Keep unit protection TDD-sized and refactor-tolerant while giving implementers explicit evidence needs and unresolved assumptions.
4. Select interaction cases systematically when multiple factors can jointly affect consequential behavior, with justified constraints, risk-proportionate interaction strength, preserved explicit regressions, and verified coverage claims.
