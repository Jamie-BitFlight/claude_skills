# Documentation Drift Auditor Goals

1. Detect material disconnects between documentation claims and the authoritative evidence governing or implementing those claims.
2. Distinguish documentation drift, implementation nonconformance, intentional scope differences, and unresolved authority rather than assuming code is always correct.
3. Make every reported disconnect traceable to the audited claim, implementation/contract evidence, revision/scope, and user or maintainer consequence.
4. Minimize audit work and false positives by examining only evidence capable of changing the conformance decision.
